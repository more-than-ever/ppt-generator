# SlideFlow - 极简 AI 智能演示文稿生成平台

Windows 本机演示文稿工作台：AI 生成整套文案与风格化排版，交 GPT Image 2 输出整页成图；程序排版作为可随时编辑回退的底座。支持文稿库、内容编辑、配图、风格、检查、自动保存、版本恢复及可编辑 PPTX 导出。所有文稿与密钥都留在本机，源码与仓库不含任何凭据。

---

## ✨ 核心能力

### 1. 🧠 整套初稿 + 逐页精修
- 一次生成交付整套幻灯片初稿（标题、副标题、正文要点、版式与配色），也可对单页就地改写；
- 文案带事实锚点：正文条目要求含可溯源的数字或来源，杜绝假大空与凭空编造；
- 结构与容量自检：字数超版式容量、区域重叠、画面缺字/多字等问题在「检查」栏逐项列出，需人工确认后才放行。

### 2. 🖼️ GPT Image 2 整页生图
- 由 DeepSeek 产出风格化排版方案与提示词，交 GPT Image 2（Grsai 中转）生成整页画面，摆脱横平竖直的模板感；
- **画面文字严格等于页面文字**：提示词以「」双向守门，凭空多出的小标签/口号/页脚与缺失文字都会被打回修正，保证成图与编辑内容一致；
- 编辑本页文字后自动回退程序排版，可一键重新生成；生成中 / 失败 / 完成三态可视，失败可重试且不自动重复付费。

### 3. 🎨 独立浮动配图
- **背景图**：用文字描述意图，交给生图模型融入整页氛围；
- **独立插图**：支持一次多张上传或 AI 生成，DeepSeek 仅依据文字排版为其**留位摆位**（无需读图、不调用多模态），插图不压文字；
- 程序排版与整页图两种模式下都会叠加显示，导出 PPTX 同样带图。

### 4. 🎭 AI 定制风格
- 不再从固定色卡里挑：AI 依据主题提炼设计令牌（风格名称、色彩意象、配色、氛围），只对用户展示名称与描述；
- 可按一句描述重新生成整套风格，换风格时自动清理不再匹配的旧成图。

### 5. 📤 原生导出与本机自持
- `pptxgenjs` 导出可编辑文本框、图形与嵌入图片；文字溢出或缺失资产会阻断正式导出；
- 文稿保存在本机 `data/`，支持版本记录、自包含 `.slideflow.json` 备份与恢复。

## 🚀 快速启动

### 方式一：Windows 免安装一键启动
双击根目录 **`一键启动网站.bat`**：优先使用 `runtime/node.exe`，自动检查依赖、构建与端口，并拉起浏览器打开 `http://localhost:3001`。

### 方式二：命令行（开发者）
```bash
npm ci            # 首次安装依赖
npm run build     # 构建前端
npm start         # 启动后端（同时托管 API 与编译后的前端）

# 或在开发模式下启动（Vite 热重载，前端 5173，/api 代理到 3001）
npm run dev
```
启动成功后访问 👉 `http://localhost:3001`（生产）或 `http://localhost:5173`（开发）。

## ⚙️ 模型配置（首次使用必读）

源码与仓库**不含任何密钥**，`.env` 已被 `.gitignore` 忽略，克隆后需自行配置：

1. 复制 `.env.example` 为 `.env`，或直接在页面「本机模型设置」中填写（保存会写回本机 `.env`）；
2. 需要两组兼容 OpenAI 格式的接口：

```env
PORT=3001

# 文案模型（DeepSeek 等兼容 OpenAI 格式接口）
LLM_API_KEY=填写你自己的密钥
LLM_API_URL=https://api.deepseek.com
LLM_MODEL=供应商实际支持的模型名

# 图片模型（GPT Image 2，经 Grsai 等中转）
GPTIMAGE2_API_KEY=填写你自己的密钥
GPTIMAGE2_API_URL=https://api.grsai.com/v1
GPTIMAGE2_MODEL=gpt-image-2
```

未配置模型时仍可手工编辑与导出；AI 生成功能需填好上述凭据后使用。

## 🧱 技术栈

React 18 + Vite 5 + TailwindCSS（前端）· Node.js + Express（后端）· pptxgenjs（导出）· DeepSeek（文案与排版方案）· GPT Image 2 via Grsai（整页生图）。

## 📂 项目结构

```
ppt生成/
├── index.html                # 网页入口
├── server.js                 # Express 后端：API 网关与配置读写
├── server/                   # 文案服务、生图任务队列、本地存储、提示词与文本守卫
├── shared/                   # 文稿 schema、版式几何、场景构建与设计令牌（前后端共用）
├── src/                      # React 前端
│   ├── App.jsx               # 主应用与交互状态机（内容 / 配图 / 风格 / 检查 四栏）
│   ├── components/           # 文稿初始化、设置弹窗、幻灯片预览等组件
│   └── services/             # API 交互与 PPTX 导出
├── tests/                    # 本地回归与端到端用例
├── 一键启动网站.bat          # Windows 快捷启动
├── .env.example              # 配置模板（不含密钥）
└── README.md
```

> `npm test` 运行本地回归；`npm run test:e2e` 运行 Playwright 端到端；真实模型采样用 `npm run test:live`（需已配置可用凭据）。
