# SlideFlow - 极简 AI 智能演示文稿生成平台

Windows 本机演示文稿工作台：AI 辅助整理文案与生成独立插图，程序负责16:9原生文字排版。支持文稿库、直接编辑、检查、自动保存、版本恢复及可编辑PPTX导出。

---

## ✨ 核心特色功能

### 1. 💬 智能对话逐页共创 (Interactive Co-Creation)
- **自然语言交流定制**：告别冰冷生硬的预设模板，通过自然语言对话向 AI 交代页面主题与演说目标；
- **共享排版场景**：19种版式、4套主题，预览与导出采用相同文字和几何数据；
- **文案权限与检查**：保留完整正文和全部独立流程步骤；AI局部修改先展示对比，由用户应用。来源引用与模型复核不能代替事实核验；
- **内页纯净设计**：严格区分封面与正文页，正文内页杜绝多余生造的虚假副标题，保持画面的极简与专业。

### 2. 🎨 独立配图与原生文字
- **图文分离**：AI只生成不含文字的插图；标题、正文、流程节点由程序排版，无图版式不调用生图。Grsai采用提交任务后查询同一ID的异步接口，失败不会自动重新付费；
- **配图风格自由多元**：根据内容属性自然融合视觉媒介，不拘泥于单一的 3D 背景板：
  - **高端商务纪实摄影**：办公协作、会议研讨、精密工业、人机交互实景；
  - **现代极简扁平矢量插图**：业务链路、技术拓扑、规范流程图解；
  - **真实产品 UI / 数据仪表盘**：数据监控、SaaS 报表与分析看板；
  - **3D 概念立体装置**：宏观愿景、前沿算法与数字基底。

### 3. 🛠️ 交互微调与原生导出
- **本地图片**：支持PNG/JPEG/WebP上传，默认完整等比显示；明确选为背景的图片可裁切；
- **在线即时编辑**：标题、文案均支持直接点击二次修改，排版不满意可一键返工修订；
- **原生 PPTX 导出**：通过 `pptxgenjs` 输出可编辑文本框、图形和嵌入图片；溢出或缺失资产阻断正式导出。不同Office软件和字体环境可能有差异，Keynote尚未实测。

## 🚀 快速启动

### 方式一：Windows 免安装一键启动（给家人/他人发布版·推荐）
直接双击根目录下的 **`一键启动网站.bat`**：
- **运行环境**：优先使用 `runtime/node.exe`，启动器检查依赖、构建和端口；缺少依赖时需先安装Node.js并执行 `npm ci`；
- **模型配置**：读取本机 `.env`，源码不内置密钥。未配置模型仍可手工编辑；AI功能需在设置中填写实际模型与凭据；
- ✅ **自动打开网页**：运行后会自动拉起默认浏览器并打开 `http://localhost:3001`。

### 方式二：命令行启动（开发者模式）
```bash
# 1. 启动生产服务（包含后端 API 与编译后的前端）
npm start

# 或在开发模式下启动（带 Vite 热重载）
npm run dev
```

启动成功后，在浏览器访问：
👉 **`http://localhost:3001`**（生产模式）或 **`http://localhost:5173`**（开发模式）

## ⚙️ 配置文件说明 (`.env`)

按 `.env.example` 填写本机配置，或在设置页保存。不要分享包含密钥的 `.env`：

```env
# 服务运行端口
PORT=3001

# 独立配图 API
GPTIMAGE2_API_KEY=填写你自己的密钥
GPTIMAGE2_API_URL=https://api.grsai.com/v1
GPTIMAGE2_MODEL=gpt-image-2

# 大语言模型 API（DeepSeek）
LLM_API_KEY=填写你自己的密钥
LLM_API_URL=https://api.deepseek.com
LLM_MODEL=填写供应商实际支持的模型
```

> 文稿保存在 `data/`，请定期导出自包含 `.slideflow.json` 备份。`npm test` 运行本地回归，`npm run test:e2e` 运行浏览器验收；真实采样必须显式启用 `LIVE_PRODUCT_TEST=1`。
>
> 当前图片限制：已向Grsai提交两次真实任务，返回图片的下载地址被本机安全检查阻断，未完成实际图片效果验收；不绕过内网地址保护、不自动重试。文字编辑及本地图片上传不依赖该服务。
