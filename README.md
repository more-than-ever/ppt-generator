# SlideFlow - 极简 AI 智能演示文稿生成平台

一个现代化、极简美学、专业高质感的 AI 商业演示文稿（PPT）生成与共创平台。通过**大模型对话交互逐页共创**与**成品级 16:9 幻灯片渲染引擎**，让每一页幻灯片兼具扎实的商业业务逻辑、精炼有力的文案、以及大师级的视觉版式。

---

## ✨ 核心特色功能

### 1. 💬 智能对话逐页共创 (Interactive Co-Creation)
- **自然语言交流定制**：告别冰冷生硬的预设模板，通过自然语言对话向 AI 交代页面主题与演说目标；
- **智能排版大局规划**：AI 自动根据页面属性（核心论据、业务流程、数据指标等）在 6 大经典商业版式（横向卡片矩阵、中心图解锚定、反向左图右文、分层阶梯流等）中动态轮转；
- **文案极致落地，拒绝假大空**：内置严格的商务文案约束与空话禁词库，杜绝泛滥套话口号，强制将抽象构想具象化为落地业务动作与机制，每个要点控制在 15-25 字，短促有力；
- **内页纯净设计**：严格区分封面与正文页，正文内页杜绝多余生造的虚假副标题，保持画面的极简与专业。

### 2. 🎨 GPT 16:9 成品级图文渲染 (Full-Slide Rendering)
- **整页图文并茂**：大模型直接将排版与文案渲染为高清晰度 16:9 成品幻灯片，自带清晰中文排版字样；
- **配图风格自由多元**：根据内容属性自然融合视觉媒介，不拘泥于单一的 3D 背景板：
  - **高端商务纪实摄影**：办公协作、会议研讨、精密工业、人机交互实景；
  - **现代极简扁平矢量插图**：业务链路、技术拓扑、规范流程图解；
  - **真实产品 UI / 数据仪表盘**：数据监控、SaaS 报表与分析看板；
  - **3D 概念立体装置**：宏观愿景、前沿算法与数字基底。

### 3. 🛠️ 交互微调与原生导出
- **本地图片自由融入**：支持拖拽上传本地业务图片或产品图，AI 自动在生图指令中指引融合；
- **在线即时编辑**：标题、文案均支持直接点击二次修改，排版不满意可一键返工修订；
- **原生 PPTX 导出**：基于 `pptxgenjs` 一键导出原生 Microsoft PowerPoint (`.pptx`) 文件，在 PowerPoint、WPS Office、Keynote 中无损秒开二次编辑。

## 🚀 快速启动

### 方式一：Windows 一键启动（推荐）
直接双击根目录下的 **`一键启动网站.bat`** 即可自动运行前后端并拉起浏览器。

### 方式二：命令行启动
```bash
# 1. 安装依赖
npm install

# 2. 启动生产服务（包含后端 API 与编译后的前端）
npm start

# 或在开发模式下启动（带 Vite 热重载）
npm run dev
```

启动成功后，在浏览器访问：
👉 **`http://localhost:3001`**（生产模式）或 **`http://localhost:5173`**（开发模式）

## ⚙️ 配置文件说明 (`.env`)

在项目根目录下复制 `.env.example` 为 `.env`：

```env
# 服务运行端口
PORT=3001

# GPT 成品图生图 API（支持 gpt-image-2 或兼容接口）
GPTIMAGE2_API_KEY=your_api_key_here
GPTIMAGE2_API_URL=https://api.grsai.com/v1
GPTIMAGE2_MODEL=gpt-image-2

# 大语言模型 API（负责对话沟通、大纲规划与文案润色，默认 glm-4-flash）
LLM_API_KEY=your_llm_key_here
LLM_API_URL=https://open.bigmodel.cn/api/paas/v4
LLM_MODEL=glm-4-flash
```

> **提示**：除了在 `.env` 中配置外，您也可以直接在网站右上角的 **「API 设置」** 弹窗中可视化输入并一键保存生效。
